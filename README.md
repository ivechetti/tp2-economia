# Laboratorio Virtual: Políticas Públicas en Economía Cerrada

Aplicación web interactiva que simula el efecto de políticas públicas sobre un mercado: calcula equilibrios, excedentes del consumidor y del productor, gasto público y variación del bienestar social. Trabajo práctico grupal de la materia Economía (Ingeniería en Informática, UNSTA).

## Qué simula

- **Ejercicio 1, subsidio al transporte:** efecto de un subsidio unitario sobre precios, cantidad de equilibrio y gasto público.
- **Ejercicio 2, alquileres urbanos:** efecto de un precio máximo legal, con cálculo de escasez y pérdida de bienestar.

## Funcionalidades

- Sliders para ajustar el subsidio y el precio máximo en tiempo real
- Gráficos interactivos de oferta y demanda
- Tabla comparativa de escenarios

## Tecnologías

Python, Streamlit, Plotly, Pandas, NumPy

## Cómo ejecutarlo

```bash
git clone https://github.com/ivechetti/tp2-economia.git
cd tp2-economia
pip install -r requirements.txt
streamlit run app.py
```
